Overchat — Design System

About the project

In one week, I designed and assembled the cross-platform design system ELMO for the AI ​​startup Overchat. The system covers three platforms - Web, iOS and Android - and has become the basis for 1,000+ product screens.

Problem

Overchat grew quickly: the team expanded, new features were added, and web and mobile versions were simultaneously developed. At the same time, there was no single system - each screen was assembled from scratch, components were duplicated, and visual consistency between platforms was lost. This slowed down the design, complicated handoffs to development, and created inconsistencies in the product.

Task

Create a unified design system that:

Ensures visual and functional consistency on Web, iOS and Android

Will speed up screen assembly and reduce time-to-market for new features

Simplify communication between design and development through clear specifications and code-ready components

System structure

Tokens

Typography. A single typographic scale in the Geist font - from display (40px, SemiBold) to small captions (12px, Regular). For each style, the size, line-height and style are specified, taking into account the rendering features on each platform.

Color palette. An extensive palette with gradations for each color family: from rich accent shades to muted background shades. The palette is adapted for Web, iOS and Android - it takes into account differences in the display of colors on different screens.

UI components

More than 20 components, most with code export support for quick transfer to development:

badge, button, sidebar, loaders, card, message, notification, label, chips, bubble, header, bottomBar, lists, radiobuttons, iconButton, input, snackbar, helper-buttons, links, dropdown and others.

Each component is designed with state variants, adapted to three platforms, and ready to use out of the box.

Approach

When designing ELMO, I adhered to several principles:

Cross-platform as a basis. Each element of the system - from tokens to components - exists in three versions: [web], [ios], [android]. These are not three separate systems, but a single architecture with platform adaptations.

Code-ready components. Most components are ready to be exported to code - this reduces the gap between mockups and implementation and reduces the number of iterations when transferring to development.

Scalability. The system is built so that new components and tokens can be easily added without disrupting the existing structure. This is critical for a startup where the product changes quickly.

Result

1,000+ screens collected on the ELMO base while working on Overchat - this confirms that the system works not in theory, but in production.

3 platforms — Web, iOS and Android — are covered by a single system, which ensures a consistent user experience regardless of the device.

2 weeks — deadline for creating the first version of the system. The quick launch allowed the team to immediately start working according to common standards, rather than waiting for months for the “perfect” system.

20+ components with code export support - developers receive ready-made specifications, rather than interpreting layouts by eye.

What's next

ELMO continues to develop along with the product. The plans include expanding the library of patterns (composite screen templates), adding a dark theme and deepening the documentation with guidelines for using each component.
